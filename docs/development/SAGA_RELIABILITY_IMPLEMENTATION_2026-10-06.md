# Saga reliability implementation

Design: [accepted reliability review](SAGA_RELIABILITY_REVIEW_2026-10-06.md). Baseline: `a8a956b5`. Scope: every numbered finding and non-CI improvement. GitHub Actions and CI configuration are excluded.

## Invariants

- Jobs commit only to their originating chat and current generation.
- A failed save preserves the last durable data. An acknowledged index record has recoverable payloads.
- Successful generation commits are never repeated because metadata checkpointing failed.
- Flush, backup, recovery and UI success distinguish optimistic changes from durable acknowledgment.
- Invalid or unresolved required Context constraints cannot silently admit content.
- Cancellation, teardown and resource budgets have explicit ownership.

## Provider contract and remaining host limits

The release host API was inspected with authenticated GitHub CLI reads on 2026-10-06. [SillyTavern `generateRaw` and `generateQuietPrompt`](https://github.com/SillyTavern/SillyTavern/blob/release/public/script.js) accept no request signal; raw generation owns an internal controller associated with the global stop event. Saga therefore advertises unsupported cancellation and serializes its raw/quiet route. It does not broadcast the host global stop event, which would affect unrelated host work. [ConnectionManagerRequestService](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/extensions/shared.js) accepts `custom.signal` and forwards it to the provider request; Saga supplies that signal. Direct OpenAI-compatible fetch also receives the signal. Profile concurrency is one and direct-endpoint concurrency is two; callers may narrow these capacities.

Every request, including Deck requests, has a default five-minute total deadline that includes waiting for a route lease. Stream readers use a thirty-second idle deadline, a 1 MiB wire/output budget, and a 64 KiB unfinished SSE-event budget; callers can specify other positive limits. Readers cancel on abort/failure and release their lock on every exit. If an adapter ignores cancellation, Saga returns the caller's timeout/cancellation promptly, rejects late progress/results, and retains the route lease until its underlying request/read/cancel settles. A permanently hung adapter keeps that route quarantined; subsequent callers expire without overlapping it. Leases coordinate Saga requests within the loaded module, not independent extensions or other browser tabs.

Browser fetch streams enforce actual byte limits before collecting an entire response. A host adapter that exposes only `response.text()` or a fully generated string cannot provide a pre-allocation byte guarantee; Saga checks that result before publication and still enforces its total caller deadline. Current host raw/quiet APIs cannot be proven stopped without host support. Tests use controlled adapters and real local persistence boundaries; live host/provider behavior remains a host-dependent validation step.
